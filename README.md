# Keepers for AI

AI 이미지·영상 생성 서비스의 채택률과 결과물당 비용을 기록해, 구독 유지 여부와 서비스 선택을 판단하게 돕는 웹앱입니다.
keeper는 사진가들이 여러 컷 가운데 쓸 만한 한 컷을 건졌을 때 부르는 말입니다.

## 화면 구성 (v2)
1. 첫 화면: 앱 소개와 keeper의 뜻, 시작하기, 예시로 결과 보기. 기록이 있으면 다음부터는 작업 화면으로 바로 열립니다.
2. 작업 화면: 서비스·요금제 설정(정한 뒤에는 한 줄로 접힘), 결과마다 못 쓰겠다/쓸 만하다, 못 쓴 이유와 고치는 방향, 이번 작업의 짧은 숫자.
3. 결과 화면: 이번 작업 결과(든 금액·걸린 시간·전력 참고치·못 쓴 이유), 이번 달 전체 결론, 잘 먹힌 프롬프트, 결과 요약.

## 핵심 기능
1. 생성 결과별 채택·폐기 기록 (만들면서 바로 누르기 / 직접 숫자로 적기)
2. 서비스별 채택률·결과물당 비용 비교와 요약 결론, 이번 달 쓴 금액, 결과 요약 보기·복사
3. 채택된 프롬프트 보관과 재사용 (복사, 지나간 결과에도 나중에 남기기)
4. 못 쓴 이유 고르기(선택) → 고치는 방향 안내와 AI에게 보낼 수정 요청문 복사, 서비스별로 주로 실패한 이유 집계

## 계산 규칙
- 이번 달 기록만 계산합니다.
- 정액제 결과물당 비용 = 월 요금 × (이번 달 지난 날수 ÷ 이번 달 전체 날수) ÷ 이번 달 채택 수
- 걸린 시간: 같은 서비스에서 연달아 누른 간격의 평균 × (생성 횟수 ÷ 채택 수). 8초 미만 간격과 이미지 10분·영상 20분을 넘는 간격은 제외하고, 간격이 3개 이상일 때만 표시합니다.
- 전력 참고치(추정): 공개 모델을 잰 연구 값의 범위로 계산합니다. 이미지 1장 약 0.6~2.9Wh(MIT Technology Review 2025, Luccioni 외 2024), 5초 영상 1개 약 30~944Wh(MIT Technology Review 2025). 실제 서비스의 값은 공개되지 않았습니다. 스마트폰 완충은 약 15Wh로 봅니다.
- 이번 작업: 작업 화면에 들어와 기록을 시작한 때부터. "새 작업 시작"을 누르거나 마지막 기록 뒤 3시간이 지나면 새 작업으로 봅니다. 월 구독의 이번 작업 금액은 "이번 달 생성 1회당 비용 × 이번 횟수"로 추정합니다.
- 서비스당 10회 미만이면 결론을 내지 않습니다. 이미지는 이미지끼리, 영상은 영상끼리만 비교합니다.

## 데이터

- 계정, 로그인, 서버, 외부 키를 쓰지 않는 단일 HTML 파일입니다.
