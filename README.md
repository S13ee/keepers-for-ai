# Keepers for AI

AI 이미지·영상 생성 서비스의 채택률과 결과물당 비용을 기록해, 구독 유지 여부와 서비스 선택을 판단하게 돕는 웹앱입니다.
keeper는 사진가들이 여러 컷 가운데 쓸 만한 한 컷을 건졌을 때 부르는 말입니다.

## 핵심 기능 (v1)
1. 생성 결과별 채택·폐기 기록 (만들면서 바로 누르기 / 직접 숫자로 적기)
2. 서비스별 채택률·결과물당 비용 비교와 요약 결론, 결과 요약 복사
3. 채택된 프롬프트 보관과 재사용 (복사)

## 계산 규칙
- 이번 달 기록만 계산합니다.
- 정액제 결과물당 비용 = 월 요금 × (이번 달 지난 날수 ÷ 이번 달 전체 날수) ÷ 이번 달 채택 수
- 서비스당 10회 미만이면 결론을 내지 않습니다. 이미지는 이미지끼리, 영상은 영상끼리만 비교합니다.

## 데이터
- 기록은 사용자 브라우저(localStorage)에만 저장되며 외부로 보내지 않습니다.
- 요금제 목록은 2026-10-08 기준 월 결제 정가(부가세 미포함)입니다. 달러 요금은 화면의 환율(기본 1,340원)로 환산합니다.
- 계정, 로그인, 서버, 외부 키를 쓰지 않는 단일 HTML 파일입니다.
